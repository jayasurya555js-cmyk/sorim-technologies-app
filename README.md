# Sorim Technologies Dashboard

A React dashboard application for managing school information, users, and student records.

## Getting Started

### Prerequisites

- Node.js and npm

### Install dependencies

From the project directory, run:

```bash
npm install
```

### Run the application

```bash
npm start
```

The development server opens the app at [http://localhost:3000](http://localhost:3000). Changes to the source files reload automatically.

## Available npm scripts

| Command | Description |
| --- | --- |
| `npm start` | Starts the development server. |
| `npm test` | Runs the test suite in interactive watch mode. |
| `npm run build` | Creates an optimized production build in the `build` directory. |
| `npm run eject` | Copies the Create React App configuration into the project. This is a one-way operation. |
